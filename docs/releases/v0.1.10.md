# Counterlock v0.1.10

A stabilization release focused on reliable analytics, clearer navigation, and a more consistent desktop experience.

## Highlights

- The global command palette now supports Ctrl+K / Cmd+K, Escape, arrow-key selection, Enter, mouse selection, grouped results, and platform-appropriate shortcut labels. Hero, item, and player searches route to their relevant views; player searches carry the query into Discover and start automatically.
- Discover keeps successful analytics available when a secondary request fails, identifies unavailable data sources, and preserves mounted panels during refresh. Player search accepts names, account IDs, SteamID64, Steam3, and Steam profile URLs; exact IDs open the matching profile directly. Team Builder prevents duplicate heroes across teams and enforces six-player sides. Lane Assistant keeps its four selections unique, handles live-match prefill collisions, and can open Build Lab for the selected hero.
- Hero Hub ability descriptions no longer expose raw markup, ability upgrade paths show readable ability names and point order, and the leaderboard can sort by player rank or matches played. Selection menus now match the dark desktop theme.
- Contextual navigation now carries hero selections from Hero Hub, live match, and match review into the right view; item searches and player lookups from the command palette open in Discover.
- The desktop sidebar reads its version from package metadata. The package, Tauri, and Cargo desktop metadata are synchronized at v0.1.10.
- Companion formatting issues are fixed without weakening CI checks.

## Reliability and test coverage

- Extracted and tested Hero Hub analytics transformations for win rates, sample-size filtering, rank aggregation, duration grouping, patch windows, and item/build/matchup sorting.
- Added tests for command-palette routing and keyboard behavior, team and lane hero uniqueness, and partial analytics failures.
- Player match history is kept account-scoped while it refreshes, and match review navigation opens the newest available match without leaking another profile's cached rows.
- Companion checks pass: Rust formatting, Clippy with warnings denied, 58 tests, and debug and release builds.
