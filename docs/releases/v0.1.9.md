# Counterlock v0.1.9

This release adds a full hero analytics workspace, broader discovery tools, clearer live team-composition context, and Steam-linked match history. It also improves the live build advisor's use of purchases observed during the current match.

## Hero Hub

- Added **Heroes** as a first-class desktop tab, with a searchable roster and sortable hero cards.
- Compare win rate, match volume, pick share, ban rate, and recent trend across queue, rank, and time filters.
- Added client-build patch windows. Patch boundaries are estimated from published build timestamps because the analytics API does not expose an exact match-to-build filter.
- Each hero profile now brings together overview stats, win/loss totals, rank and match-duration breakdowns, and base-stat growth.
- Added item outcomes and purchase timing, common item-flow transitions, community build guides, guide outcome samples, ability descriptions and upgrades, ability-leveling orders, hero matchups, teammate results, and player leaderboards.
- Added filters for same-lane matchups, ability orders conditioned on selected items, and leaderboard metrics.
- Sample sizes and data limitations are shown alongside historical rates. Matchup and teammate results are observational and do not establish causation.

## Discover and team planning

- Expanded **Discover** with dedicated Items, Meta, Leaderboards, Players, My Stats, Team Builder, and Lane Assistant sections.
- Team Builder now summarizes documented ability-mechanic strengths and potential coverage gaps for both teams, with evidence coverage and confidence context.
- Lane Assistant can be prefilled from the current live lane assignments. Lane assignments may be estimates and are labeled accordingly.
- Live match view now includes an allied team ability profile and supported strengths or potential gaps alongside the existing enemy threat profile.

## Live build advisor

- The advisor records item additions only after a known inventory baseline for the active match, and re-establishes that baseline after inventory data gaps.
- Observed purchases can condition item-flow evidence by the stage in which the purchase occurred, so a current-match sequence can inform the next-buy plan.
- Improved analysis refresh inputs so changes in the player's hero, personal profile, live threats, lane opponent, buy target, or observed purchases trigger a fresh recommendation.
- Fixed an empty timed-purchase result path that could crash live matchup analysis. Missing samples now remain empty instead of being treated as a populated row.

## My Matches and match review

- Added Steam profile linking by profile name or numeric account ID, including candidate selection when a name is ambiguous.
- Linked profiles load Deadlock API match history; the UI reports connection, empty-history, and unavailable states distinctly.
- Added an unlink control and clearer local-versus-API history status messaging.
- Match history refresh now clears stale account results while a new account is loading.

## Data and compatibility notes

- Analytics and player history require the Deadlock API and may be unavailable or sparse for some filters, heroes, and regions.
- Patch selection uses build-time windows as an approximation; it cannot guarantee that every analytics row came from the selected client build.
- Team strengths, gaps, item outcomes, build-guide results, and hero pair rates summarize available evidence; they are not guarantees or causal claims.
- No database migration or account credential collection is introduced. Steam linking uses public profile/account identifiers; Counterlock never asks for a Steam password.

## Downloads and updates

- Linux: signed AppImage and `.deb` packages.
- Windows: signed NSIS `.exe` installer.
- The GitHub release also includes signed updater metadata for the in-app updater.
